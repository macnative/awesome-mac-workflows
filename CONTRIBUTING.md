# Contributing

Thanks for taking the time to contribute. This list only stays useful if the entries stay current, accurate, and genuinely good — please read through before opening a pull request.

## Before you submit

- **Search first.** Check the README and open pull requests to make sure the resource isn't already listed.
- **It has to be good.** The tool or resource should be actively maintained (or a stable, finished piece of software that doesn't need maintenance), solve a real macOS workflow problem, and be something you'd genuinely recommend. "I built this" is welcome, but say so in the PR description.
- **macOS only, workflow-focused.** This list is scoped to tools, scripts, and resources that help build or automate a macOS workflow — not general software, iOS-only apps, or unrelated web services.
- **One resource per pull request** makes review faster, unless you're adding several closely related items to the same new category.

## Format

Add your entry to the most relevant category, in this exact format:

```markdown
- [Name](https://example.com) - A short, factual description that ends with a period.
```

- Keep descriptions to one sentence. Say what it does, not why it's great ("the best", "amazing", "a must-have" — leave those out).
- Capitalize the first letter of the description; end with a period.
- Link to the project's official site or GitHub repo, not an affiliate link, a review article, or a download mirror.
- Entries within a category don't need to be alphabetical — place new entries where they make the most sense next to similar tools.
- If no existing category fits, propose a new `## Category Name` section, and add it to the [Contents](README.md#contents) table of contents.

## Checklist

Before opening a pull request, confirm:

- [ ] The link works and goes to the official site or repository.
- [ ] The description is one sentence, starts with a capital letter, and ends with a period.
- [ ] The entry is in the right category (or you've proposed a new one).
- [ ] You've added the new section to the table of contents, if applicable.

## Removing an entry

If a tool is discontinued, has been acquired and shut down, or no longer meets the bar above, open a pull request removing it and explain why in the description.

Thanks again for contributing!
